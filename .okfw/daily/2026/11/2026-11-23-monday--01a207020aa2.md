## Notes

- **Azure DevOps creates a pull-request-level comment as an active thread.** A branch policy that requires resolved comments would block a pull request on the bot's status comment, so the bot resolves that thread after it posts it. A later edit leaves the thread resolved (checked live).
- **Head markers are found by marker, not by author.** A person who writes a status or finding marker can make the bot skip files. This was already true for finding markers; ADR-0028 records it.
