## Notes

- **Why the templates install tools:** they target hosted runners, which start every job on a new machine. vizzini-lab runs the Azure template on a self-hosted agent only because the org has no hosted parallelism for private projects. That agent is a new container for each run.
- **.NET:** the templates install no .NET. vizzini-lab's agent image has `libicu74` because the Azure Pipelines agent is a .NET program.
